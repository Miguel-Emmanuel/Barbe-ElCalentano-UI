# Barber Shop EL CALENTANO — Web

Frontend Next.js (reserva pública + panel staff).

## Setup
```bash
npm install
npm run dev
```

Abre `http://localhost:3000`  
API esperada: `http://localhost:4000` (`NEXT_PUBLIC_API_URL`)

## Marca
- Negro / dorado / blanco + textura ladrillo
- Tipografía display: Pacifico (estilo script del logo)
- UI: DM Sans
- Moneda MXN · pago en local
